# Security policy

## Supported versions

The latest released version on nuget.org and the `main` branch are supported.
Older tags are not patched unless a release notes exception says otherwise.

## Reporting a vulnerability

Do **not** open a public issue for a security problem.

Use GitHub's private vulnerability reporting on this repository
(Security → Report a vulnerability), or contact the repository owner
directly on GitHub.

Please include:

- The package or binary (`Hypa.Ttfx`, `Hypa.Ttfx.Tool`, or the AOT `ttfx`)
- Version (`ttfx --version` or the NuGet version)
- Impact and a minimal repro if you have one

You should hear back within a week. We will credit reporters who want to be
named once a fix is released.
